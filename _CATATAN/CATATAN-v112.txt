PNW TOOLS v112 (label v9.12) — PROPS, MAKRO & MASK
==================================================
Tiga fitur ala ProPresenter dalam satu rilis — menuntaskan sisa roadmap rencana.

1) PROPS (overlay lengket)
   - Logo: tombol di remote HP -> logo melayang di atas konten dan TETAP tampil
     saat ganti slide/lagu. Ketuk lagi untuk mematikan.
   - Lower-Third: ketik teks (mis. nama pembicara) -> pita teks tampil di bagian
     bawah layar output. Ketuk "Tampilkan" dengan teks yang sama untuk mematikan.
   - "Matikan Prop" membersihkan semua prop.
   - Prop bertahan saat Clear/Black dan muncul lagi begitu konten live kembali.

2) MAKRO (satu ketuk, banyak aksi) — di remote HP
   - Pembukaan: layar Logo + timer mundur 5 menit + pesan panggung.
   - Doa: layar Black + pesan panggung "Mari kita berdoa".
   - Penutup: Clear + timer mati + pesan terima kasih (hilang otomatis 30 dtk).
   - Langkah dieksekusi berurutan oleh operator; pesan/timer ditulis langsung ke
     kanal stage message. Preset bisa diedit di js/cf-remote.js (MACRO_PRESETS).

3) MASK (pengaman proyeksi)
   - Design Panel -> baris "MASK": atur bar hitam Atas/Bawah (0-30%).
   - Berguna bila proyektor melebihi bidang tembok/layar fisik.
   - Tersimpan perangkat (pnwCastflowMask.v1) dan ikut payload live.

Teknis:
- payload() membawa overlay prop + mask (additif, kompatibel mundur).
- __remote bertambah: propSet / propOff / propOn.
- Perintah remote baru: prop / propoff / macro (langkah dieksekusi berurutan).
- Output: renderMask (#dispMask) di samping renderOverlay yang sudah ada.
- Tidak perlu publish rules baru (memakai kanal v105-v107).

Deploy:
Timpa C:\pnw-tools (pertahankan .git) -> git add -A -> git commit -m v112 ->
git push -> buka web -> Ctrl+Shift+R -> label v9.12.
