CATATAN v108 (label v9.8) — Rundown di Remote HP
=================================================
Yang baru:
- Bagian RUNDOWN di remote HP (?mode=remote): daftar rundown tampil
  realtime dari laptop operator; item yang sedang live diberi sorot biru.
- Ketuk item = lagu itu langsung live di layar (mulai dari slide pertama).
- Tombol "◀ Item" / "Item ▶" = pindah ke item rundown sebelum/berikutnya.
  Kalau belum ada yang live: "Item ▶" mulai dari item pertama.

Teknis:
- Perintah baru: item / itemnext / itemprev lewat kanal youthviews/remote.
  Operator mengeksekusi via PNWProjector.__remote.itemGo/itemStep
  (aktifkan lagu + render + goLive otomatis).
- Remote membaca pujianYouth/projector/plan (rules v80: .read auth != null)
  — TIDAK perlu publish rules baru.

Deploy:
1. Timpa isi C:\pnw-tools dengan isi ZIP (jaga folder .git).
2. git add -A && git commit -m "v108" && git push
3. Ctrl+Shift+R -> cek label v9.8.

Uji singkat:
- Laptop: buka CastFlow, susun rundown 2-3 lagu.
- HP: bagian RUNDOWN menampilkan daftar yang sama -> ketuk lagu ke-2 ->
  layar output langsung menayangkan lagu itu -> tombol Item ▶/◀ pindah lagu.
