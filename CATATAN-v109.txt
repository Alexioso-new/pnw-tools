CATATAN v109 (label v9.9) — Navigasi Lagu Efisien (Lompat ke Bagian)
====================================================================
Pemicu: umpan balik pengguna — untuk kembali ke Chorus/Verse harus menekan
Prev berkali-kali; kurang efisien saat ibadah berjalan.

Yang baru:
1. LOMPAT KE BAGIAN — chip nama bagian lagu (Verse 1, Chorus, Bridge, ...):
   - di HP remote: kotak BAGIAN LAGU (muncul otomatis saat ada lagu live)
   - di operator laptop: baris chip di atas grid slide
   Satu ketuk = langsung live di slide pertama bagian itu. Bagian yang
   sedang live diberi sorot biru.
2. NEXT/PREV LINTAS LAGU — di slide terakhir, Next langsung menayangkan
   lagu berikutnya di rundown; di slide pertama, Prev kembali ke lagu
   sebelumnya. Berlaku bila lagu ada di rundown; kalau tidak, perilaku
   lama tetap (berhenti di ujung slide).

Teknis:
- Payload live lagu kini membawa field `sections` (tambahan murni —
  output versi lama mengabaikannya).
- Operator: sectionsOf() (diekspor di __tl), __remote.goSlide(i),
  perintah remote baru `slide` dengan data.i.
- TIDAK perlu publish rules baru.

Deploy:
1. Timpa isi C:\pnw-tools dengan isi ZIP (jaga folder .git).
2. git add -A && git commit -m "v109" && git push
3. Ctrl+Shift+R -> cek label v9.9.

Uji singkat:
- Live-kan lagu yang punya beberapa bagian -> di HP ketuk "Chorus" ->
  output langsung lompat ke chorus.
- Tekan Next di slide terakhir -> lagu berikutnya di rundown langsung live.
