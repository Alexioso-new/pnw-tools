PNW TOOLS v117 (label v9.17) — PERFORMANCE + STUDIO EDIT + CAPCUT TIMELINE
============================================================================
1. Performance tanpa menurunkan kualitas output
- Free Canvas pan/zoom/drag/resize dibatch satu requestAnimationFrame.
- Transform canvas memakai translate3d + compositor; DOM frame memakai containment.
- Minimap dibatasi agar tidak berebut frame dengan gerakan utama.
- Frame di luar viewport disembunyikan dari paint dan menerima pesan pause;
  saat kembali terlihat, video/motion langsung resume.
- FPS + long-task monitor melalui CastFlowPerformance; badge muncul di Dual.
- Output aktual tetap full quality. Hanya preview tak terlihat yang dipause.

2. Bug Studio pada Preview Edit
- #projPreview kini memiliki canvas .projPreviewMotion sendiri.
- bg.kind=studio membuat instance PNWMotion, apply params, resize, dan start.
- Renderer pause ketika Preview Live/tab tersembunyi atau dokumen hidden,
  lalu resume saat Edit/Dual terlihat.
- Tidak menggandakan renderer output; setiap permukaan punya instance sendiri.

3. Timeline ala CapCut
- Toolbar ikon satu baris, ruler/track/clip/playhead baru, filmstrip/waveform visual.
- Context menu klik kanan: Edit, Split, Duplicate, Copy, Paste, Delete, Ripple.
- Ctrl+C/V/D, Ctrl+wheel zoom pada pointer, auto-follow playhead.
- Smooth playhead 60 FPS dan FPS badge.
- Track icon + collapse; lock/visibility lama tetap utuh.
- Mesin proyek/payload/transisi/undo-redo/cloud lama dipertahankan.
