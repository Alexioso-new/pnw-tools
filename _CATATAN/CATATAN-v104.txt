CASTFLOW v104 (label v9.4) — SPRINT 5: RELIABILITY + ACCESSIBILITY + PERFORMANCE
================================================================================

Melanjutkan v103 — Sprint 5 dari master plan v101. Fokus rilis ini adalah
hardening runtime untuk penggunaan panggung panjang, akses keyboard/screen
reader, dan alat diagnosis yang bisa memberi bukti, bukan tebakan.

YANG BARU
---------
1. LIFECYCLE SCHEDULER
   - Kernel sekarang dimuat sebelum UI legacy.
   - Lima polling dekoratif permanen (bahasa, Bible version, section chip,
     network/auth paint, Flow/Design sync) pindah ke scheduler sadar-visibilitas.
   - Saat tab tersembunyi job UI berhenti total dan resume saat terlihat.
   - Timer kritis heartbeat output, countdown, playback/timeline, recorder,
     dan metronome TIDAK diubah.

2. ACCESSIBILITY GUARD
   - Nama aksesibel untuk tombol ikon dan field dinamis.
   - Landmark main, skip link, semantics menu/tab/toggle, html lang.
   - Focus trap dialog, fokus awal eksplisit, dan restore focus saat tutup.
   - Audit Accessibility di Diagnostics dengan skor + jumlah kontrol tanpa label.
   - CSS focus-visible, reduced motion, higher contrast, dan forced-colors.

3. PERFORMANCE + RELIABILITY MONITOR
   - Sampel ringan tiap 15 detik: DOM nodes, resources, JS heap (jika browser
     mendukung), error count, status output, event-loop lag, dan Long Tasks.
   - Diagnostics memiliki tombol Sample, Run Accessibility, Start 2h, Stop,
     dan Export laporan JSON.
   - Soak test menilai error baru, pertumbuhan DOM/heap, lag, long task,
     dan disconnect output. State aktif dapat pulih setelah reload.

4. DIAGNOSTICS v104
   - Panel lama tetap ada: App, Output/ACK, Preflight, Media, Errors, Storage.
   - Ditambah tiga baris: Performance, Accessibility, Reliability.
