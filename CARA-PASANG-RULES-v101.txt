Langkah (2 menit):

2. Pilih Realtime Database -> tab "Rules".
3. Hapus seluruh isi lama, paste seluruh isi file database.rules.json.
4. Klik "Publish".

CATATAN PENTING:
- Jika Anda PERNAH mengubah rules sendiri dan ingin mempertahankannya,
  cukup TAMBAHKAN blok ini di dalam "pujianYouth" -> "youthviews":

    "heartbeat": {
      ".read": true,
      ".write": true,
      ".validate": "newData.hasChildren(['ts', 'sig']) && newData.child('ts').isNumber() && newData.child('sig').isString() && newData.child('sig').val().length < 200"
    }

- Node heartbeat HANYA berisi denyut status output (timestamp + tanda slide).
  Tidak ada data lirik/jemaat. Write dibuka agar layar output TANPA LOGIN
  tetap bisa melapor; isi dibatasi ketat oleh .validate.
