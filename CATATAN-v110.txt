CATATAN v110 (label v9.10) — Aransemen Lagu + Stage Monitor Mandiri
====================================================================
Melanjutkan roadmap ProPresenter: Arrangements.

Yang baru:
1. ARANSEMEN per lagu (di operator, baris ARANSEMEN di atas grid slide):
   - Tombol "+ Verse" / "+ Chorus" / ... menambah bagian ke urutan.
   - Ketuk chip aransemen untuk menghapusnya. "Reset" = kembali ke
     urutan asli lagu. Perubahan langsung tersimpan (lokal di operator).
   - Contoh: susun Verse 1 -> Chorus -> Verse 2 -> Chorus -> Chorus sekali,
     lalu saat live cukup tekan Next — slide mengikuti urutan itu.
   - Chip bagian (v109) & remote HP ikut urutan aransemen otomatis.
2. STAGE MONITOR MANDIRI — Stage Display kini membaca lirik slide kini
   DAN berikutnya langsung dari payload siaran (field baru nextLines/
   nextLabel), bukan menyusun dek sendiri. Wajib supaya tampilan panggung
   konsisten saat aransemen aktif; juga makin tahan bila perangkat panggung
   tidak punya pustaka lagu. Output lama tetap jalan (fallback ke dek lokal
   bila payload tidak membawa field baru).

Teknis:
- slidesOf() kini = applyArrangement(song, rawDeckOf(song)) — satu titik
  ubah, seluruh hilir (deck, payload, chip, remote) ikut aransemen.
- Kemunculan ke-k suatu label di aransemen memetakan ke run ke-k label itu
  di lagu; bila stok habis, clamp ke run pertama.
- Aransemen tersimpan lokal (pnwCastflowArr.v1) — TIDAK perlu publish rules.

Deploy:
1. Timpa isi C:\pnw-tools (jaga .git).
2. git add -A && git commit -m "v110" && git push
3. Ctrl+Shift+R -> label v9.10.

Uji singkat:
- Operator: buka lagu -> baris ARANSEMEN -> susun Chorus, Verse, Verse,
  Chorus -> live -> Next berjalan mengikuti urutan itu.
- Stage Display: baris "Next" menampilkan bagian/slide berikutnya dengan
  benar walau aransemen aktif.
